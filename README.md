# Landgasthof Rote Mühle — Website Demo

Premium responsive static website concept for Landgasthof Rote Mühle, Bad Soden am Taunus.

## Cloudflare Pages

Use these settings when connecting this repository:

- **Production branch:** `main`
- **Framework preset:** `None`
- **Build command:** leave empty
- **Build output directory:** `public`
- **Root directory:** leave empty / repository root

No environment variables are required.

## Notes

The demo intentionally reuses selected images and content from the existing Landgasthof website and supplements the visual direction with Unsplash imagery. The site is vanilla HTML/CSS/JS and requires no build step.
